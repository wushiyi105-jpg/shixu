# UI 说明：时序

- **谁在什么时刻打开**：给盯业务指标的运营或数据同学。
- **首屏任务句**：这段异常，是缺数还是跳变。
- **主操作**：按「传带时区数据 → 分缺失与跳变 → 导出异常时间窗」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：波形分析台；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：波形分析台。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给盯业务指标的运营或数据同学：上传带时区和单位的数据，标出基线、异常段、缺失段和阈值；人工标误报后重跑，导出时间窗和证据。
